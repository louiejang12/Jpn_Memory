# 일본어 단어퀴즈 (1–2과)

듀오링고 스타일의 일본어 단어 암기 웹앱입니다. 폰 브라우저에서 바로 쓸 수 있어요.

**시험:** 9월 29일(화) 단어퀴즈 · 범위 1–2과 단어 (204개)
- 한자 읽기 / 한국어 의미 / 한국어 → 일본어
- 한자 쓰기는 없음, 외래어(가타카나) 쓰기는 있음

## 기능
- **모든 문제는 직접 쓰기** (4지선다 없음) — 글자 타일을 눌러 조립
  - 한자 → 히라가나: 漢字를 보고 읽는 법 쓰기
  - 한국어 → 히라가나: 뜻을 보고 일본어(가나)로 쓰기
  - 외래어 → 가타카나: 외래어 뜻을 보고 가타카나로 쓰기 (シ/ツ, ソ/ン 같은 헷갈리는 글자가 섞여 나와요)
  - "키보드로 입력"을 누르면 직접 타이핑도 가능 — 영어 자판 로마자 자동 변환 (hokkaidou → ほっかいどう)
- **오답노트** — 틀린 단어가 자동으로 모이고, 복습에서 서로 다른 세션에서 2번 맞히면 졸업
- **틀린 문제 재출제** — 세션 안에서 틀린 문제는 몇 문제 뒤에 다시 나옴
- **학습 기록** — 연속 학습일, XP, 하루 목표, 14일 그래프, 범위별 숙련도, 자주 틀린 단어 TOP 10
- **과 표시** — 문제·정답·단어장·카드마다 몇 과(어느 파트) 단어인지 표시
- **효과음 & 발음** — 듀오링고 스타일 효과음(정답/오답/타일/레슨 완료), 답하면 단어를 일본어로 읽어줌
- **단어장 / 플래시카드** — 뜻·일본어 가리기, 검색, 발음 듣기
- **이어서 하기** — 퀴즈·플래시카드를 하다가 나가도 홈에서 그 문제부터 이어서 풀기
- 기록은 브라우저(localStorage)에 저장 · 기록 탭에서 백업/복원 가능
- 홈 화면에 추가하면 앱처럼 사용 가능 (오프라인 지원)

## 폰에서 쓰는 법 (GitHub Pages)
1. 이 저장소 **Settings → Pages**
2. **Source: Deploy from a branch** → 브랜치 선택 → 폴더 `/ (root)` → Save
3. 1–2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 주소로 접속
4. 사파리 공유 버튼 / 크롬 메뉴 → **홈 화면에 추가**
