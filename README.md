# 일본어 단어퀴즈 (1–4과, 6–7과)

듀오링고 스타일의 일본어 단어 암기 웹앱입니다. 폰 브라우저에서 바로 쓸 수 있어요.

**시험:** 9월 29일(화) 단어퀴즈 · 범위 1–2과 단어 (204개)
- 한자 읽기 / 한국어 의미 / 한국어 → 일본어
- 한자 쓰기는 없음, 외래어(가타카나) 쓰기는 있음

**범위 세트:** 홈 맨 위에서 **1–2과**(204단어) / **3–4과**(169단어) / **6–7과**(120단어) 중 선택 — 고른 범위는 바꿀 때까지 유지
(학습 기록·오답노트·숙련도는 단어별로 쌓이고, 화면에는 고른 세트 것만 보여요)

## 기능
- **모든 문제는 직접 쓰기** (4지선다 없음) — 글자 타일을 눌러 조립
  - 한자 → 히라가나: 漢字를 보고 읽는 법 쓰기
  - 한국어 → 히라가나: 뜻을 보고 일본어(가나)로 쓰기
  - 외래어 → 가타카나: 외래어 뜻을 보고 가타카나로 쓰기 (シ/ツ, ソ/ン 같은 헷갈리는 글자가 섞여 나와요)
  - "키보드로 입력"을 누르면 직접 타이핑도 가능 — 영어 자판 로마자 자동 변환 (hokkaidou → ほっかいどう)
- **오답노트** — 틀린 단어가 자동으로 모이고, 복습에서 서로 다른 세션에서 2번 맞히면 졸업
- **틀린 문제 재출제** — 세션 안에서 틀린 문제는 몇 문제 뒤에 다시 나옴
- **틀린 단어 다시 풀기** — 범위마다 마지막으로 틀린 단어를 저장, 결과 화면에서 못 눌러도 홈·파트 선택 창에서 나중에 다시 풀기
- **학습 기록** — 연속 학습일, XP, 하루 목표, 14일 그래프, 범위별 숙련도, 자주 틀린 단어 TOP 10
- **과 표시** — 문제·정답·단어장·카드마다 몇 과(어느 파트) 단어인지 표시
- **효과음 & 발음** — 듀오링고 스타일 효과음(정답/오답/타일/레슨 완료), 답하면 단어를 일본어로 읽어줌
- **단어장 / 플래시카드** — 뜻·일본어 가리기, 검색, 발음 듣기
- **파트 배지** — 응용회화=회화, 문법노트=문법, 표현노트=표현(6–7과), 연습노트=연습
- **파트 나눠 풀기** — 각 파트(응용회화 등)를 누르면 1-1, 1-2 … 처럼 10개 안팎씩 골라 풀기
- **다음 단계 / 클리어 횟수** — 끝까지 풀면 "다음: 1-2" 버튼으로 바로 이어서, 범위마다 몇 번 클리어했는지 표시
- **이어서 하기** — 범위마다 진행 상황을 따로 저장, 다시 누르면 "이어서 하기 / 처음부터" 선택
- **한자 쓰기** (6–7과 한자노트 6·7) — 뜻과 읽기를 보고 칸에 손가락/펜으로 직접 쓰기
  - 단계: 따라 쓰기(흐린 본보기) → 보고 쓰기(위에 작은 본보기) → 안 보고 쓰기 → 확인(내 글씨·본보기 나란히, 획 수 비교) → 맞음/틀림 스스로 판정
  - 시험 모드(홈 「한자 쓰기」 옆 버튼 또는 설정): 안 보고 쓰기만
  - 한 획 되돌리기 · 전부 지우기 · 획순 보기(번호와 함께 한 획씩 그려짐)
  - 틀린 한자는 세션 안에서 다시 나오고, 틀린 한자 목록에 쌓였다가 다른 날 2번 맞히면 졸업
  - 본보기·획순은 폰 글꼴이 아니라 KanjiVG 획 데이터로 그려서 일본 자형(変·対·転·単 등) 그대로 보여요
- 기록은 브라우저(localStorage)에 저장 · 기록 탭에서 백업/복원 가능
- 홈 화면에 추가하면 앱처럼 사용 가능 (오프라인 지원)

## 폰에서 쓰는 법 (GitHub Pages)
1. 이 저장소 **Settings → Pages**
2. **Source: Deploy from a branch** → 브랜치 선택 → 폴더 `/ (root)` → Save
3. 1–2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 주소로 접속
4. 사파리 공유 버튼 / 크롬 메뉴 → **홈 화면에 추가**

## 파일
- `words.js` — 단어 데이터 (교재 1과 p.13–14, 2과 p.26, 3과 p.42, 4과 p.56, 6과, 7과 p.96) + 한자노트(`KANJI_NOTES`, 한자노트6 p.83·7 p.97). 단어를 추가·수정하려면 이 파일만 고치면 됩니다.
  - 교재 오타 정정: 7과 冬休み 읽기가 교재엔 なつやすみ지만 뜻이 겨울방학이라 ふゆやすみ로 고침
- `kanji_strokes.js` — 한자노트 글자의 획 데이터 (자동 생성). 한자노트를 고치면 `python tools/build_strokes.py` 다시 실행 (누락 글자 0인지 출력)
- `app.js` — 앱 로직
- `style.css` — 디자인
